
# Interactive To Do List

## Overview
A simple interactive task tracker built using HTML, CSS, and JavaScript.

## Features
- Displays a list of tasks.
- Changes task colour when clicked.
- Shows a checkmark when a task is completed.
- Allows users to toggle between completed and incomplete tasks.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository.
2. Open the todo-interactive folder.
3. Open index.html in your browser.
